# Preparação da entrega

O código, os testes e o histórico Git são locais. Nome definido para o repositório: api-gerenciamento-pedidos. A publicação exige acesso à conta escolhida para a entrega. O RA será preenchido pelo aluno posteriormente.

1. Extraia o ZIP preservando a pasta oculta .git. Não use apenas "Upload files" do GitHub: isso não envia o histórico.
2. Execute npm install, npm test e npm start.
3. Importe a coleção do Postman e confira as respostas. Veja as capturas em evidencias/.
4. Revise o guia de estudo e a seção Uso de IA do README.
5. Crie um repositório vazio no GitHub, sem README inicial, licença ou .gitignore automáticos.
6. Na pasta do projeto, configure origin com a URL real e execute git push -u origin main, conforme o README.
7. Confira no GitHub se aparecem o código, package-lock.json, evidências e pelo menos cinco commits.
8. Confirme que o professor consegue acessar o repositório e entregue o link junto com o RA.
