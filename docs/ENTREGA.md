# Preparação da entrega

Repositório da atividade: https://github.com/EnzoGabrielRdS/api-gerenciamento-pedidos

O RA será preenchido pelo aluno posteriormente.

1. Clone o repositório ou extraia o ZIP preservando a pasta oculta .git.
2. Execute npm install, npm test e npm start.
3. Importe a coleção do Postman e confira as respostas. Veja as capturas em evidencias/.
4. Revise o guia de estudo e a seção Uso de IA do README.
5. Confira no GitHub se aparecem o código, package-lock.json, as cinco evidências e pelo menos cinco commits.
6. Entregue o link do repositório junto com o RA na plataforma da disciplina.

- Repositório: https://github.com/EnzoGabrielRdS/api-gerenciamento-pedidos

O registro de uso de IA consta no README; o aluno permanece responsável por compreender e revisar o trabalho.
